# Project 3 – SQL Data Analysis

## Project Overview

This project focuses on analyzing an **E-commerce Orders Dataset** using **SQL and MySQL**. The analysis explores customer orders, products, sales, payment methods, order status, discounts, and revenue to generate meaningful business insights.

## Goal

The main goal of this project is to use SQL queries to analyze e-commerce data and identify **sales trends, customer behavior, product performance, and business insights** that can support data-driven decision-making.

## Dataset

The dataset contains **1,200 e-commerce order records** with information such as:

* Order ID
* Order Date
* Customer ID
* Product
* Quantity
* Unit Price
* Shipping Address
* Payment Method
* Order Status
* Tracking Number
* Items in Cart
* Coupon Code
* Referral Source
* Total Price

## Tools & Technologies

* **MySQL**
* **SQL**
* **Git & GitHub**

## Analysis Performed

The project includes SQL analysis such as:

* Total sales and revenue analysis
* Product-wise sales analysis
* Customer order analysis
* Payment method analysis
* Order status analysis
* Coupon and discount analysis
* Referral source analysis
* Monthly sales analysis
* Identification of top-performing products
* Aggregation using `SUM()`, `COUNT()`, `AVG()`, `MIN()`, and `MAX()`
* Data filtering and sorting
* `GROUP BY` and `HAVING`
* SQL joins and subqueries

## Key Outcomes

The analysis helps identify:

* Best-selling products
* High-revenue products
* Customer purchasing patterns
* Popular payment methods
* Order completion and cancellation trends
* Sales performance over time
* Effectiveness of coupons and referral sources

## How to Run the Project

1. Install and start MySQL.
2. Create the decodelabs_project3 database.
3. Create the orders table.
4. Import the CSV dataset.
5. Open sql/project3_queries.sql.
6. Run the SQL queries in MySQL.
